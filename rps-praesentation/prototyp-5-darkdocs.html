01

Spielstand

V1 speichert die Punkte im Spiel – je Spieler ein eigenes Attribut. V2 gibt jedem Spieler seine eigenen Punkte.

02

Beziehung

V1: gerichtete Assoziation, das Spiel kennt beide Spieler dauerhaft. V2: nur Übergabe als Parameter in spielStarten(pS1, pS2).

03

Sieger

siegerErmitteln() liefert in V1 ein Spieler-Objekt, in V2 einen String.

!

Fehler in beiden Diagrammen

c · Beurteilen

Zentral oder verteilt?

Version 1 zentral
  • Spiel steuert alles – Spieler bleibt schlank
  • Assoziation: Zugriff auf beide Spieler in jeder Runde
  • Sieger als Objekt – alle Daten abrufbar
  • Doppelte Attribute S01/S02 → Redundanz
  • Schlecht erweiterbar für mehr Spieler
Version 2 verteilt
  • Punkte liegen beim Spieler – hohe Kohäsion
  • Kein doppelter Code, besser erweiterbar
  • Ohne Assoziation kennt rundeStarten() die Spieler nicht
  • Setter für Punkte schwächen die Kapselung
  • Sieger nur als String
d · Entscheiden & Dokumentieren

Entscheidung: Version 1.

● gewählt
Version 1

Vollständig und konsistent: Das Spiel kennt beide Spieler in jeder Runde. Für genau zwei Spieler ist die Redundanz vertretbar.

Klasse Spiel
Spiel()erzeugt zwei Spieler, setzt Namen und alle Zähler auf 0
spielStarten()setzt Runde und Rundenpunkte zurück, startet beide Spieler neu
rundeStarten()vergleicht die Symbole und vergibt den Rundenpunkt
siegerErmitteln()liefert den Spieler mit 2 Punkten, sonst null

e · Implementieren

Wie eine Runde entschieden wird.

Spiel.java rundeStarten()
public void rundeStarten()
{
    runde = runde + 1;
    String s1 = spieler01.getAktSymbol();
    String s2 = spieler02.getAktSymbol();

    if (s1.equals(s2))
    {
        System.out.println("Runde " + runde + ": Unentschieden");
    }
    else if ((s1.equals("Stein") && s2.equals("Schere"))
          || (s1.equals("Schere") && s2.equals("Papier"))
          || (s1.equals("Papier") && s2.equals("Stein")))
    {
        rundenpunkteS01 = rundenpunkteS01 + 1;  // Spieler 1
    }
    else
    {
        rundenpunkteS02 = rundenpunkteS02 + 1;  // Spieler 2
    }
}
