Aufgabe c · Beurteilen

Version 1 vs. Version 2

Version 1

  • Spiel steuert alles zentral – Spieler bleibt einfach
  • Assoziation: Zugriff auf beide Spieler in jeder Runde
  • Sieger als Objekt – alle Daten abrufbar
  • Doppelte Attribute S01/S02 (Redundanz)
  • Für einen 3. Spieler müsste man alles umbauen
VS

Version 2

  • Punkte gehören zum Spieler – logisch sauber
  • Kein doppelter Code, besser erweiterbar
  • Ohne Assoziation kennt rundeStarten() die Spieler nicht
  • Setter für Punkte schwächen die Kapselung
  • Sieger nur als String

Spiel.javapublic void rundeStarten()
{
    runde = runde + 1;
    String s1 = spieler01.getAktSymbol();
    String s2 = spieler02.getAktSymbol();

    if (s1.equals(s2))
    {
        System.out.println("Runde " + runde + ": Unentschieden");
    }
    else if ((s1.equals("Stein") && s2.equals("Schere"))
          || (s1.equals("Schere") && s2.equals("Papier"))
          || (s1.equals("Papier") && s2.equals("Stein")))
    {
        rundenpunkteS01 = rundenpunkteS01 + 1;  // Spieler 1
    }
    else
    {
        rundenpunkteS02 = rundenpunkteS02 + 1;  // Spieler 2
    }
}
