Getter, wenn eine andere Klasse den Wert lesen muss. Setter nur, wenn er von außen geändert werden muss – sonst bleibt das Attribut gekapselt. Kein setAktSymbol(): das übernimmt symbolUebermitteln(). In V2 muss das Spiel die Punkte im Spieler setzen.
  • Prinzip Datenkapselung: Attribute sind private, Zugriff nur über Methoden.
  • V1: Start braucht die Getter, um Stand und Spieler abzufragen; setName, weil das Spiel die Namen vergibt.
  • V2: Spiel muss Punkte im Spieler ändern → zusätzliche Setter.
// Aufgabe c · Beurteilen

Vor- und Nachteile im Sachzusammenhang.

Version 1 zentral
Spiel steuert alles – Spieler bleibt schlank
Assoziation: Zugriff auf beide Spieler in jeder Runde
Sieger als Objekt – alle Daten abrufbar
Doppelte Attribute S01/S02 → Redundanz
Schlecht erweiterbar für mehr Spieler
Version 2 verteilt
Punkte liegen beim Spieler – hohe Kohäsion
Kein doppelter Code, besser erweiterbar
Ohne Assoziation kennt rundeStarten() die Spieler nicht
Setter für Punkte schwächen die Kapselung
Sieger nur als String

Kernproblem von Version 2: Die Spieler werden zwar übergeben, aber nirgends gespeichert – in jeder neuen Runde fehlt der Zugriff.

  • V1 ist einfacher und funktioniert sofort, aber Daten der Spieler liegen im Spiel.
  • V2 ist objektorientiert „schöner“, aber unvollständig: ohne Assoziation kein Zugriff in rundeStarten().
// Aufgabe d · Entscheiden & Dokumentieren

Entscheidung: Version 1.

✓ gewählt
Version 1

Vollständig und konsistent: Das Spiel kennt beide Spieler in jeder Runde. Für genau zwei Spieler ist die Redundanz vertretbar.

Klasse Spiel
Spiel()erzeugt zwei Spieler, setzt Namen und alle Zähler auf 0
spielStarten()setzt Runde und Rundenpunkte zurück, startet beide Spieler neu
rundeStarten()vergleicht die Symbole und vergibt den Rundenpunkt
siegerErmitteln()liefert den Spieler mit 2 Punkten, sonst null
Klasse Spieler
Spieler()setzt Name, Runde und Symbol auf Startwerte
symbolUebermitteln(p)speichert das Symbol und erhöht die Runde
symbolWaehlen()liest das Symbol per Scanner ein (Ergänzung)
  • Begründung: V1 ist vollständig – das ist für die Umsetzung entscheidend.
  • Methoden kurz durchgehen; symbolWaehlen() haben wir ergänzt, damit man über die Konsole spielen kann.
// Aufgabe e · Implementieren – Programmablauf

Start: die Spielschleife.

Start.java main()
public class Start
{
    public static void main(String[] args)
    {
        Spiel spiel = new Spiel();
        spiel.spielStarten();

        while (spiel.siegerErmitteln() == null)
        {
            spiel.getSpieler01().symbolWaehlen();
            spiel.getSpieler02().symbolWaehlen();
            spiel.rundeStarten();
            System.out.println("Stand: " + spiel.getRundenpunkteS01()
                             + " : " + spiel.getRundenpunkteS02());
        }

        System.out.println("Sieger: " + spiel.siegerErmitteln().getName());
    }
}

// Aufgabe e · Implementieren – Klasse Spiel

Wie eine Runde entschieden wird.

Spiel.java rundeStarten()
public void rundeStarten()
{
    runde = runde + 1;
    String s1 = spieler01.getAktSymbol();
    String s2 = spieler02.getAktSymbol();

    if (s1.equals(s2))
    {
        System.out.println("Runde " + runde + ": Unentschieden");
    }
    else if ((s1.equals("Stein") && s2.equals("Schere"))
          || (s1.equals("Schere") && s2.equals("Papier"))
          || (s1.equals("Papier") && s2.equals("Stein")))
    {
        rundenpunkteS01 = rundenpunkteS01 + 1;  // Spieler 1
    }
    else
    {
        rundenpunkteS02 = rundenpunkteS02 + 1;  // Spieler 2
    }
}
Regeln Spieler 1 gewinnt, wenn …
✊schlägt"Stein" vs "Schere"✌️
✌️schlägt"Schere" vs "Papier"✋
✋schlägt"Papier" vs "Stein"✊
Gleiches Symbol → Unentschieden, kein Punkt.
Alles andere → Punkt für Spieler 2.
  • Drei Fälle: gleich → unentschieden; eine der drei Gewinnkombinationen → Spieler 1; sonst Spieler 2.
  • Strings immer mit equals() vergleichen, nicht mit ==.
// Aufgabe e · Implementieren – Sieger & Testlauf

Wer zuerst 2 Punkte hat, gewinnt.

Spiel.java siegerErmitteln()
public Spieler siegerErmitteln()
{
    if (rundenpunkteS01 == 2)
    {
        return spieler01;
    }
    if (rundenpunkteS02 == 2)
    {
        return spieler02;
    }
    return null;  // noch kein Sieger
}
