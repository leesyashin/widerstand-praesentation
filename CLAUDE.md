# Repo-Hinweise

- `index.html` im Root ist eine bestehende Präsentation – **nicht verändern**.
- Die Präsentations-App **Studio** lebt komplett in `studio/`. Regeln: `studio/CLAUDE.md`, Plan: `studio/PLAN.md`,
  Stil: `studio/STYLE.md`. Befehle immer im Ordner `studio/` ausführen.
- Decks bauen oder ändern: Projekt-Skill `/deck` (`.claude/skills/deck/SKILL.md`).
